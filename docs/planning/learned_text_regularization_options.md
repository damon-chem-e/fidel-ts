# Learned Regularization for Text Modulation in Lynx-FiLM

## Problem Statement

The Lynx-FiLM model uses text information to modulate LayerNorm outputs via FiLM conditioning:

$$z_{\text{modulated}} = (1 + \gamma) \odot \text{LayerNorm}(z) + \beta$$

Where $\gamma, \beta \in \mathbb{R}^{B \times C \times d}$ are generated from text embeddings.

**Current behavior**: The model always applies text modulation with equal weight, regardless of whether the text is informative for the current prediction task.

**Desired behavior**: Learn to automatically attenuate text influence when text information is not useful, while preserving strong modulation when text is relevant.

---

### Mathematical Formulation of Current System

For layer $\ell$ in the encoder:

**Attention Block:**
$$h^{(\ell)} = \text{Attn}(z^{(\ell-1)}) + z^{(\ell-1)}$$
$$\hat{h}^{(\ell)} = \text{LayerNorm}(h^{(\ell)})$$
$$\tilde{h}^{(\ell)} = (1 + \gamma_1^{(\ell)}) \odot \hat{h}^{(\ell)} + \beta_1^{(\ell)}$$

**FFN Block:**
$$f^{(\ell)} = \text{FFN}(\tilde{h}^{(\ell)}) + \tilde{h}^{(\ell)}$$
$$\hat{f}^{(\ell)} = \text{LayerNorm}(f^{(\ell)})$$
$$z^{(\ell)} = (1 + \gamma_2^{(\ell)}) \odot \hat{f}^{(\ell)} + \beta_2^{(\ell)}$$

Where the modulation parameters are generated by:
$$[\gamma_1^{(\ell)}, \beta_1^{(\ell)}, \gamma_2^{(\ell)}, \beta_2^{(\ell)}] = \text{FiLMGen}^{(\ell)}(\text{flatten}(T))$$

With $T \in \mathbb{R}^{B \times C \times L \times d_{\text{text}}}$ being the text embeddings.

## Option 1: Global Scalar Gate (Simplest)

### Concept
Learn a single scalar gate $\alpha \in [0, 1]$ that controls the overall influence of text modulation across all layers and channels.

### Mathematical Formulation

Introduce a learnable parameter $\alpha_{\text{raw}} \in \mathbb{R}$ with gating:
$$\alpha = \sigma(\alpha_{\text{raw}})$$

Modified modulation:
$$\tilde{h}^{(\ell)} = (1 + \alpha \cdot \gamma_1^{(\ell)}) \odot \hat{h}^{(\ell)} + \alpha \cdot \beta_1^{(\ell)}$$

When $\alpha \to 0$:
$$\tilde{h}^{(\ell)} \to \hat{h}^{(\ell)}$$
(pure iTransformer behavior)

When $\alpha \to 1$:
$$\tilde{h}^{(\ell)} = (1 + \gamma_1^{(\ell)}) \odot \hat{h}^{(\ell)} + \beta_1^{(\ell)}$$
(full FiLM modulation)

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│                    OPTION 1: GLOBAL SCALAR GATE                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Text Embeddings                                                │
│  [B, C, L, d_text]                                             │
│        │                                                        │
│        ▼                                                        │
│  ┌──────────────┐                                              │
│  │ FiLMGenerator│──────▶ γ, β                                  │
│  └──────────────┘          │                                   │
│                            │                                    │
│                            ▼                                    │
│                     ┌─────────────┐                            │
│                     │  α = σ(α_raw)│  ◄── Learnable scalar     │
│                     └─────────────┘                            │
│                            │                                    │
│                            ▼                                    │
│                       α·γ, α·β                                  │
│                            │                                    │
│  LayerNorm output          │                                    │
│  ẑ ─────────────────────▶ ⊗ ──▶ (1 + α·γ)⊙ẑ + α·β             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- Minimal parameter addition (1 scalar)
- Easy to interpret and debug
- Fast to train
- Can regularize via $L_2$ penalty on $\alpha_{\text{raw}}$ to bias toward ignoring text

### Cons
- No sample-wise or channel-wise adaptivity
- Cannot learn "text helps for channel A but not channel B"
- Cannot adapt based on input content

### Implementation Complexity
**Low** - Single `nn.Parameter` + sigmoid + multiplication

## Option 2: Per-Layer Scalar Gates

### Concept
Learn a separate gate $\alpha^{(\ell)} \in [0, 1]$ for each encoder layer, allowing the model to learn that text is useful at certain depths but not others.

### Mathematical Formulation

For each layer $\ell \in \{1, ..., L_{\text{enc}}\}$:
$$\alpha^{(\ell)} = \sigma(\alpha^{(\ell)}_{\text{raw}})$$

Modified modulation at layer $\ell$:
$$\tilde{h}^{(\ell)} = (1 + \alpha^{(\ell)} \cdot \gamma_1^{(\ell)}) \odot \hat{h}^{(\ell)} + \alpha^{(\ell)} \cdot \beta_1^{(\ell)}$$
$$z^{(\ell)} = (1 + \alpha^{(\ell)} \cdot \gamma_2^{(\ell)}) \odot \hat{f}^{(\ell)} + \alpha^{(\ell)} \cdot \beta_2^{(\ell)}$$

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│                  OPTION 2: PER-LAYER GATES                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    Encoder Layer 1                       │   │
│  │                                                          │   │
│  │   Text ──▶ FiLMGen¹ ──▶ γ¹,β¹ ──▶ [α¹·γ¹, α¹·β¹]       │   │
│  │                                        │                 │   │
│  │   z ──▶ Attn ──▶ LN ──────────────────▶⊗ ──▶ z¹        │   │
│  │                                                          │   │
│  │   where α¹ = σ(α¹_raw)  ◄── learnable per layer         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    Encoder Layer 2                       │   │
│  │                                                          │   │
│  │   Text ──▶ FiLMGen² ──▶ γ²,β² ──▶ [α²·γ², α²·β²]       │   │
│  │                                        │                 │   │
│  │   z¹ ──▶ Attn ──▶ LN ─────────────────▶⊗ ──▶ z²        │   │
│  │                                                          │   │
│  │   where α² = σ(α²_raw)                                   │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              ▼                                  │
│                            (...)                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- Can learn depth-specific text relevance
- Still interpretable (3 scalars for 3 layers)
- Low parameter overhead

### Cons
- Still no sample-wise adaptivity
- Cannot distinguish between channels

### Implementation Complexity
**Low** - `nn.Parameter(torch.zeros(e_layers))`

## Option 3: Per-Channel Static Gates

### Concept
Learn a gate vector $\boldsymbol{\alpha} \in [0, 1]^C$ that controls text influence per channel. This allows the model to learn that some variables benefit from text while others don't.

### Mathematical Formulation

Learnable: $\boldsymbol{\alpha}_{\text{raw}} \in \mathbb{R}^{C}$
$$\boldsymbol{\alpha} = \sigma(\boldsymbol{\alpha}_{\text{raw}}) \in [0,1]^C$$

Broadcast for modulation (per channel $c$):
$$\tilde{h}^{(\ell)}_{:,c,:} = (1 + \alpha_c \cdot \gamma_{1,c}^{(\ell)}) \odot \hat{h}^{(\ell)}_{:,c,:} + \alpha_c \cdot \beta_{1,c}^{(\ell)}$$

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│                OPTION 3: PER-CHANNEL STATIC GATES               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Channel indices:     c=1    c=2    c=3   ...   c=C            │
│                        │      │      │           │              │
│                        ▼      ▼      ▼           ▼              │
│  Learnable gates:    [α₁,    α₂,    α₃,   ...,  αc]            │
│                       │       │      │           │              │
│                       │       │      │           │              │
│                       ▼       ▼      ▼           ▼              │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │              Per-Channel Gated Modulation                │   │
│  │                                                          │   │
│  │   For each channel c:                                    │   │
│  │                                                          │   │
│  │   γ_c, β_c from FiLMGen                                  │   │
│  │        │                                                 │   │
│  │        ▼                                                 │   │
│  │   [α_c · γ_c,  α_c · β_c]                               │   │
│  │        │                                                 │   │
│  │        ▼                                                 │   │
│  │   z_c = (1 + α_c·γ_c) ⊙ ẑ_c + α_c·β_c                   │   │
│  │                                                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  Result: Different channels can have different text reliance    │
│          (e.g., α_temperature ≈ 0.9, α_humidity ≈ 0.1)         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- Channel-specific text reliance
- Useful when some variables are text-driven and others are not
- Still relatively interpretable

### Cons
- Requires knowing channel count at model init (not always fixed)
- No sample-wise adaptivity
- May not generalize to unseen channels

### Implementation Complexity
**Low-Medium** - Requires handling variable channel counts

## Option 4: Input-Conditioned Gating (Dynamic)

### Concept
Learn a gating function $g: \mathbb{R}^{d} \to [0, 1]$ that produces per-sample, per-channel gates based on the time series input. This allows the model to dynamically decide text relevance based on the actual input.

### Mathematical Formulation

**Gate Network:**
$$\boldsymbol{\alpha} = \sigma(W_g \cdot \bar{x} + b_g)$$

Where:
- $\bar{x} = \text{mean}(x, \text{dim}=\text{time}) \in \mathbb{R}^{B \times C}$ (temporal mean per channel)
- $W_g \in \mathbb{R}^{1 \times 1}$, $b_g \in \mathbb{R}$ (shared across channels)
- Output: $\boldsymbol{\alpha} \in [0, 1]^{B \times C}$

**Alternative: Richer Gate Network**
$$\boldsymbol{\alpha} = \sigma(\text{MLP}(\bar{x}))$$

Where MLP: $\mathbb{R}^{C} \to \mathbb{R}^{C}$

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│             OPTION 4: INPUT-CONDITIONED GATING                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Time Series Input                Text Embeddings               │
│  x: [B, seq_len, C]               T: [B, C, L, d_text]         │
│        │                                   │                    │
│        │                                   ▼                    │
│        │                            ┌──────────────┐            │
│        │                            │ FiLMGenerator│            │
│        │                            └──────────────┘            │
│        │                                   │                    │
│        │                              γ, β [B, C, d]            │
│        │                                   │                    │
│        ▼                                   │                    │
│  ┌──────────────┐                          │                    │
│  │ Temporal Mean│                          │                    │
│  │ x̄ = mean(x)  │                          │                    │
│  └──────────────┘                          │                    │
│        │                                   │                    │
│        │ [B, C]                            │                    │
│        ▼                                   │                    │
│  ┌──────────────┐                          │                    │
│  │  Gate MLP    │                          │                    │
│  │  α = σ(MLP)  │                          │                    │
│  └──────────────┘                          │                    │
│        │                                   │                    │
│        │ α: [B, C]                         │                    │
│        │                                   │                    │
│        └──────────────────┬────────────────┘                    │
│                           │                                     │
│                           ▼                                     │
│                 α·γ, α·β  [B, C, d]                             │
│                           │                                     │
│                           ▼                                     │
│              (1 + α·γ) ⊙ ẑ + α·β                               │
│                                                                 │
│  Note: Gate is computed ONCE and applied to all layers         │
│        (or can be per-layer with separate gate networks)        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- Sample-wise adaptivity: can ignore text for some samples, use it for others
- Can learn complex patterns (e.g., "ignore text when variance is high")
- Most flexible option

### Cons
- More parameters
- Harder to interpret
- Risk of overfitting
- May be unstable during early training

### Implementation Complexity
**Medium** - Requires gate MLP + proper initialization

## Option 5: Text Quality-Conditioned Gating

### Concept
Instead of conditioning on time series input, condition on the text embeddings themselves. If the text encoder produces low-confidence or low-information embeddings, automatically attenuate their influence.

### Mathematical Formulation

**Text Summary:**
$$\bar{T} = \text{mean}(T, \text{dim}=(\text{seq}, \text{text\_dim})) \in \mathbb{R}^{B \times C}$$

Or use attention pooling:
$$\bar{T} = \sum_i \text{softmax}(W_q \cdot T_i) \cdot T_i$$

**Gate from Text:**
$$\boldsymbol{\alpha} = \sigma(W_t \cdot \bar{T} + b_t)$$

### Architecture Diagram

│            OPTION 5: TEXT QUALITY-CONDITIONED GATING            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Text Embeddings                                                │
│  T: [B, C, L, d_text]                                          │
│        │                                                        │
│        ├────────────────────────────────┐                       │
│        │                                │                       │
│        ▼                                ▼                       │
│  ┌──────────────┐                ┌──────────────┐              │
│  │ FiLMGenerator│                │ Text Pooling │              │
│  │              │                │ (mean/attn)  │              │
│  └──────────────┘                └──────────────┘              │
│        │                                │                       │
│        │ γ, β                           │ T̄: [B, C, d] or [B,C]│
│        │                                │                       │
│        │                                ▼                       │
│        │                         ┌──────────────┐              │
│        │                         │  Gate MLP    │              │

│        │                                │                       │

│                        ▼                                        │
│              α·γ, α·β  [B, C, d]                                │
│                        │                                        │
│                        ▼                                        │
│           (1 + α·γ) ⊙ ẑ + α·β                                  │
│                                                                 │
│  Intuition: If text embeddings are "uncertain" or "generic",    │
│             the gate learns to attenuate their influence        │
│                                                                 │

```

### Pros
- Self-calibrating based on text quality
- Can learn to detect uninformative text patterns
- Doesn't require time series features for gating

### Cons
- Circular dependency risk (text produces gate that affects text usage)
- May not detect when text is confident but irrelevant

### Implementation Complexity
**Medium** - Similar to Option 4

## Option 6: Cross-Modal Attention Gating

### Concept
Use a cross-attention mechanism where time series queries against text keys/values. The attention weights naturally indicate text relevance, which can be used as soft gates.

### Mathematical Formulation

**Cross-Attention Gate:**
$$Q = W_Q \cdot \bar{x}, \quad K = W_K \cdot \bar{T}, \quad V = \mathbf{1}$$
$$\boldsymbol{\alpha} = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) \cdot V$$

Where:
- $\bar{x} \in \mathbb{R}^{B \times C \times d}$ is the pooled time series representation
- $\bar{T} \in \mathbb{R}^{B \times C \times d}$ is the pooled text representation

**Simplified Version:**
$$\boldsymbol{\alpha} = \sigma\left(\frac{\langle \bar{x}, \bar{T} \rangle}{\tau}\right)$$

Where $\tau$ is a learnable temperature and $\langle \cdot, \cdot \rangle$ is dot product similarity.

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│            OPTION 6: CROSS-MODAL ATTENTION GATING               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Time Series                      Text Embeddings               │
│  x: [B, seq_len, C]               T: [B, C, L, d_text]         │
│        │                                   │                    │
│        ▼                                   ▼                    │
│  ┌──────────────┐                   ┌──────────────┐           │
│  │  Embed + Pool│                   │  FiLM + Pool │           │
│  │  x̄: [B,C,d]  │                   │  T̄: [B,C,d]  │           │
│  └──────────────┘                   └──────────────┘           │
│        │                                   │                    │
│        │ Query                             │ Key                │
│        │                                   │                    │
│        └───────────────┬───────────────────┘                    │
│                        │                                        │
│                        ▼                                        │
│              ┌─────────────────────┐                           │
│              │  Cross-Attention    │                           │
│              │                     │                           │
│              │  α = σ(Q·K^T / τ)   │                           │
│              │                     │                           │
│              │  τ = learnable temp │                           │
│              └─────────────────────┘                           │
│                        │                                        │
│                        │ α: [B, C]                             │
│                        │                                        │
│                        ▼                                        │
│              ┌─────────────────────┐                           │
│              │  Gated Modulation   │                           │

│              │  (1 + α·γ)⊙ẑ + α·β │                           │
│              └─────────────────────┘                           │
│                                                                 │

│             α is low when they are "misaligned" or text is noise│
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- Principled: attention naturally measures relevance
- Sample and channel-specific
- Gradient flows through both modalities

### Cons
- More complex
- Requires aligned representation spaces
- May need careful initialization

### Implementation Complexity
**Medium-High** - Cross-attention + temperature + projection layers

## Option 7: Auxiliary Regularization Loss

### Concept
Instead of architectural changes, add a regularization term to the loss function that penalizes large modulation magnitudes. This encourages the model to only use text modulation when it provides clear benefit.

### Mathematical Formulation

**Modulation Magnitude Penalty:**
$$\mathcal{L}_{\text{reg}} = \lambda \sum_{\ell} \left( \|\gamma^{(\ell)}\|_2^2 + \|\beta^{(\ell)}\|_2^2 \right)$$

**Total Loss:**
$$\mathcal{L} = \mathcal{L}_{\text{forecast}} + \mathcal{L}_{\text{reg}}$$

**Adaptive Version (penalize more when prediction is already good):**
$$\mathcal{L}_{\text{reg}} = \lambda \cdot \exp(-\mathcal{L}_{\text{forecast}}) \cdot \left( \|\gamma\|_2^2 + \|\beta\|_2^2 \right)$$

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│           OPTION 7: AUXILIARY REGULARIZATION LOSS               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │               Standard Forward Pass                      │   │
│  │                                                          │   │
│  │   Text ──▶ FiLMGen ──▶ γ, β ──▶ Modulation ──▶ ŷ       │   │
│  │                         │                     │          │   │
│  │                         │                     │          │   │
│  │                         ▼                     ▼          │   │
│  │               ┌─────────────────┐    ┌──────────────┐   │   │
│  │               │ ‖γ‖² + ‖β‖²    │    │ L_forecast   │   │   │
│  │               │ (magnitude)     │    │ = MSE(ŷ, y)  │   │   │
│  │               └─────────────────┘    └──────────────┘   │   │
│  │                         │                     │          │   │
│  └─────────────────────────┼─────────────────────┼──────────┘   │
│                            │                     │              │
│                            ▼                     ▼              │
│                    ┌────────────────────────────────────┐       │
│                    │                                    │       │
│                    │  L_total = L_forecast + λ·L_reg   │       │
│                    │                                    │       │
│                    │  where L_reg = ‖γ‖² + ‖β‖²       │       │
│                    │                                    │       │
│                    └────────────────────────────────────┘       │
│                                                                 │
│  Effect: Model learns to minimize γ,β magnitudes unless        │
│          they provide sufficient forecast improvement           │
│                                                                 │
│  λ tuning:                                                      │
│    - Higher λ → stronger bias toward ignoring text             │
│    - Lower λ  → allows more text influence                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- No architectural changes needed
- Differentiable and easy to implement
- Hyperparameter $\lambda$ controls text reliance directly

### Cons
- Global penalty, not sample-specific
- Requires tuning $\lambda$
- May hurt performance on text-relevant datasets

### Implementation Complexity
**Very Low** - Add term to loss function

## Option 8: Hybrid - Gated Modulation with Initialization Bias

### Concept
Combine architectural gating (Option 4 or 6) with careful initialization that biases the gates toward 0 (ignoring text). The model must learn to "open" the gate if text is useful.

### Mathematical Formulation

**Biased Initialization:**
$$\alpha_{\text{raw}} \sim \mathcal{N}(-2, 0.1)$$
$$\implies \alpha = \sigma(\alpha_{\text{raw}}) \approx 0.12$$

**With Learnable Bias Term:**
$$\alpha = \sigma(\text{GateNetwork}(x) + b_{\text{init}})$$
$$b_{\text{init}} = -2 \quad \text{(initialized, learnable)}$$

### Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│        OPTION 8: GATED MODULATION WITH INITIALIZATION BIAS      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Initialization Philosophy:                                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                          │   │
│  │   Default behavior: IGNORE text (α ≈ 0)                 │   │
│  │   Model must LEARN to use text (α → 1)                  │   │
│  │                                                          │   │
│  │   This is the "guilty until proven innocent" approach   │   │
│  │                                                          │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  Implementation:                                                │
│                                                                 │
│  x ──▶ GateNetwork ──▶ logit                                   │
│                          │                                      │
│                          ▼                                      │
│                   logit + b_init     where b_init = -2         │
│                          │                                      │
│                          ▼                                      │
│                    α = σ(logit + b_init)                       │
│                          │                                      │
│                          │                                      │
│                          ▼                                      │
│            ┌─────────────────────────────┐                     │
│            │  At initialization:          │                     │
│            │  α = σ(-2) ≈ 0.12           │                     │
│            │  → Text has ~12% influence   │                     │
│            │                              │                     │
│            │  After training (if useful): │                     │
│            │  Gate learns positive logit  │                     │
│            │  α → higher values           │                     │
│            └─────────────────────────────┘                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pros
- Combines flexibility of learned gates with "text skepticism" prior
- Model must prove text is useful before using it
- Works well for mixed datasets (some text-relevant, some not)

### Cons
- May slow convergence on text-relevant tasks
- Requires careful balance of initialization

### Implementation Complexity
**Medium** - Gate network + custom initialization

## Recommended Approach

For the Lynx-FiLM use case, I recommend a **staged implementation**:

### Stage 1: Quick Validation
Implement **Option 7 (Auxiliary Loss)** to validate the hypothesis that text regularization helps. This requires minimal code changes.

### Stage 2: Baseline Gating
If Stage 1 shows improvement, implement **Option 2 (Per-Layer Gates)** or **Option 1 (Global Gate)** to add learned adaptivity with minimal complexity.

### Stage 3: Full Dynamic Gating
For maximum flexibility, implement **Option 8 (Hybrid)** combining:
- Input-conditioned gating (Option 4)
- Initialization bias toward ignoring text
- Optional auxiliary regularization loss

This progression allows validating each step before adding complexity.

class GatedFiLMGenerator(nn.Module):
    def __init__(self, text_dim, output_dim, seq_len=1, hidden_dim=None):
        super().__init__()
        self.film_gen = FiLMGenerator(text_dim, output_dim, seq_len, hidden_dim)
        self.gate_raw = nn.Parameter(torch.tensor(0.0))  # Initialize at 0.5 after sigmoid

    def forward(self, x):
        gamma1, beta1, gamma2, beta2 = self.film_gen(x)
        alpha = torch.sigmoid(self.gate_raw)
        return alpha * gamma1, alpha * beta1, alpha * gamma2, alpha * beta2
```

### Option 4 Implementation

```python
class InputConditionedGate(nn.Module):
    def __init__(self, d_model, hidden_dim=64):
        super().__init__()
        self.gate_net = nn.Sequential(
            nn.Linear(d_model, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1),
        )

    def forward(self, x):
        # x: [B, seq_len, C] -> pool -> [B, C]
        x_pooled = x.mean(dim=1)  # [B, C]
        gate_logits = self.gate_net(x_pooled.unsqueeze(-1))  # [B, C, 1]
        alpha = torch.sigmoid(gate_logits).squeeze(-1)  # [B, C]
        return alpha
```

### Option 7 Implementation

```python
def compute_film_regularization(film_params, lambda_reg=0.01):
    """
    film_params: list of (gamma1, beta1, gamma2, beta2) tuples from each layer
    """
    reg_loss = 0.0
    for gamma1, beta1, gamma2, beta2 in film_params:
        reg_loss += torch.mean(gamma1 ** 2) + torch.mean(beta1 ** 2)
        reg_loss += torch.mean(gamma2 ** 2) + torch.mean(beta2 ** 2)
    return lambda_reg * reg_loss
```
